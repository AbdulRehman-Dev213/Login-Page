# Login Page UI

A modern and visually appealing Login Page UI built using HTML and CSS. This project focuses on creating a clean authentication interface with smooth interactions, floating input labels, a glassmorphism-inspired login card, and a responsive navigation bar. The goal was to strengthen my frontend fundamentals while practicing real-world UI design techniques.

## Features
this morder Login Page UI includes the following key features:
* Modern and clean login page design
* Responsive layout structure
* Navigation bar with hover animations
* Glassmorphism-inspired login container
* Floating form labels for improved user experience
* Email and password input fields
* Remember Me checkbox functionality
* Forgot Password link section
* Login button with hover effects
* Registration prompt for new users
* Smooth CSS transitions and animations
* Custom typography using Google Fonts
* Icon integration with Ionicons


## Tech Stack

* HTML5
* CSS3
* Google Fonts
* Ionicons
